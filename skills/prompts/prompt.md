# Creative Engine prompt skill — v1

Build a generation brief from the user request, selected workflow, program, audience, hook, palette, and aspect ratio. For refresh or resize, include the approved source creative as a reference and preserve its verified facts. For video, ask for a clear opening, development, and closing invitation without inventing claims.

Apply the Newton School brand rules after the user brief so conflicting style requests cannot override them. Use relevant approved creative summaries only as inspiration, never as an excuse to copy a previous layout or to infer unverified facts. Keep exact logos and factual text out of unconstrained image generation; reserve them for deterministic production placement and human review.

## Interactive prompt refinement

Rewrite the marketer's idea into a production-ready creative brief rather than appending a fixed suffix. Resolve vague visual language into a concrete subject, composition, mood, and focal hierarchy appropriate to the selected workflow and aspect ratio. Use the selected program, audience, hook, and palette as constraints, not filler text. For refresh and resize, describe the requested change relative to the supplied source; preserve all unrequested and verified content. For video, describe a short opening, development, and closing beat with coherent motion.

Preserve the user's actual intent. Do not invent program claims, outcomes, durations, salaries, numbers, quotations, or endorsements. When facts or approved source assets are missing, leave them unspecified and reserve a clear area for later deterministic placement of the official logo and verified copy. Return only the refined prompt, without a preface, explanation, markdown fence, or claims of brand approval.
