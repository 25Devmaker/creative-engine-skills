# Creative Engine skills

Portable, project-local skills for Newton School creative production. This repository is private and contains the supplied 2026 brand guide, approved logo lockups, Mona Sans fonts, and prompt/design references. The runnable Next.js Creative Engine is maintained separately in [25Devmaker/creative-engine](https://github.com/25Devmaker/creative-engine).

Start with the [installation and usage guide](creative-engine/.agents/skills/README.md). The main workflows are [New Creatives](creative-engine/.agents/skills/new-creatives/SKILL.md), [Refresh Creatives](creative-engine/.agents/skills/refresh-creatives/SKILL.md), [Reframe and Resize](creative-engine/.agents/skills/reframe-and-resize/SKILL.md), and [Videos](creative-engine/.agents/skills/videos/SKILL.md).

Keep the repository layout intact: the skills link to the [official 2026 brand guide](skills/brand/official-2026-guidelines.md), approved assets, and shared prompt references by relative path. An [export ZIP](creative-engine/deliverables/creative-engine-skills-export.zip) is also provided. Tool connections, account access, and API credentials are not included.
