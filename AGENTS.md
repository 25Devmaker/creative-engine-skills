# Creative Engine skills instructions

This repository packages Newton School Creative Engine skills and their supporting brand and prompt references. It is not the runnable Creative Engine application. The canonical Next.js, Supabase, and OpenRouter app remains in the separate `25Devmaker/creative-engine` repository.

At the start of project work, read `creative_engine_context_for_chatgpt.md` and `decisions.md`. For any Newton School image or video, read `skills/brand/official-2026-guidelines.md` and inspect its paired PNG before creating media. Use the approved full logo lockup and Mona Sans assets in `creative-engine/memory/brand/assets/`; never invent claims, RTBs, learner identities, or consent.

Keep secrets out of this repository. Treat tool connections and provider permissions as account-specific; the skills do not install or transfer them. Make scoped changes and record meaningful changes in `decisions.md` as they happen.
